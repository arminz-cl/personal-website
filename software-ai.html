jobscout

An LLM scores job postings against a rubric I wrote and returns a ranked shortlist. A pluggable provider layer runs it on Groq, Gemini, or Claude. Two-tier design: a batched pass scores everything cheaply, then a deeper single-posting pass with full reasoning and gap analysis on the top picks. Also generates a tailored resume per role from a source-of-truth experience file. Python engine, FastAPI backend, React frontend. Built with Claude Code.

Danaa

A Telegram assistant that answers immigration questions for Iranian newcomers to Canada, with real users. RAG over years of real community chat history, plus a knowledge-distillation layer that compresses noisy conversation into clean, structured fact cards the retriever ranks over. Gemini API, with a dashboard to inspect and monitor the knowledge base. The interesting problem is turning messy human chat into something a model can retrieve against reliably.
